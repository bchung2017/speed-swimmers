## Art direction (from 05)

The default car sets the rendering style; images 01–04 set mood, not fidelity.

- Low-poly, flat-shaded faceted surfaces — no smooth normals on body panels.
- Body: deep-blue late-90s sport-compact coupe (tuner, not exotic) — rounded wedge nose, tall rear wing on swept end plates. Facet contrast does the shading work.
- Glass: dark red tint, black trim.
- Front: cyan headlight elements with an amber outboard corner, amber side marker, rectangular cyan fog lights in the lower bumper.
- Rear: full-width red taillight bar with red-orange outer segments, recessed plate area.
- Red neon underglow strips along the side skirts and front lip, casting red light on the ground.
- Wheels: silver five-spoke, black tyres.
- Environment (not shown in 05; extrapolated): blocky low-poly skyline, warm amber window lights, sparse cyan signage, faceted dark ground.
- Palette anchors: deep-blue body `~#1d2f86`, red underglow `~#ff1020`, cyan `~#5fe0f0` emissive, amber `~#ffb040` markers, near-black navy sky.
- No manufacturer badges anywhere on the in-game model (including wheel center caps).
